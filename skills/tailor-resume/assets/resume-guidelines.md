# Résumé guidelines (curated from VisualCV resume-guide)

`tailor-resume` and `score-jd` should apply these. Source: visualcv.com/blog/resume-guide.

## Structure & sections
- Order: Header → Summary → Experience → Education → Skills → optional (Projects, Certifications, Publications, Languages).
- Header: name as largest text + contact + relevant profile links. Lead with a clear job title/identity.
- Layout by situation: chronological (default), functional (gaps/career-change), combination.
- Keep a master profile; cut a tailored résumé per application.
- **Omit** objective statements, references, "references available upon request."
- Photo: omit for N.A. résumés; expected on many European CVs — driven by `locales.json`.

## Length & format
- 1–2 pages (academic CVs longer). Clean layout over cramming.
- **Submit PDF** (preserves formatting, ATS-parseable). Never Word.
- Keep ATS-parseable: contact/work/skills must extract cleanly (single column, real text).
- Pass the ~6–7 second scan: focused, compelling, relevant.

## Summary
- Highlight strongest, results-oriented accomplishments — or omit (no summary beats a weak one).
- Specific > fluff: "Results-driven … 10+ yrs, blue-chip clients" not "passionate problem solver."

## Experience bullets
- Reverse-chronological; per entry: employer, dates, title, accomplishment bullets.
- **Accomplishments, not duties.** Start each bullet with a strong action verb (Designed, Led,
  Launched, Reduced, Grew, Delivered, Boosted).
- **Quantify** with real numbers (%, $, time, scale). Active voice.

## Skills
- List explicitly; prioritize skills that match the JD (what ATS screens for).
- Senior: keep education brief. Never inflate credentials.

## Tailoring to the JD
- Customize per application. Identify the employer's problem + ideal-candidate profile; position as that.
- **Mirror JD keywords** so ATS ranks you higher (use `skill-keywords.json`).

## Avoid
- Objective/references/photo (N.A.) · duties instead of quantified wins · one generic résumé ·
  vague fluff · inflated credentials · Word format · unfocused everything-résumé.
